# Extension Tests

## test_sites.js
Simulated dropdown DOM structures from 20+ real Indian govt sites (SSC, BPSC, BSF, UPSC, Rajasthan, UPPSC, NTA, IBPS, RRB, DSSSB, HPSC, MPSC, TNPSC, KPSC, WBPSC, RPSC, CGPSC, JPSC, OPSC, APPSC).

## test_teaching.js
Tests the teaching detection logic (getDisplayText + root finding) against all 20 sites.

### Run
```
cd /tmp && npm install jsdom
node /opt/cybercontrol-hub/tests/test_teaching.js
```
